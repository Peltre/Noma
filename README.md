# Noma

Una app de finanzas personales para ver, de un vistazo, cuánto tienes y cuánto de eso ya tiene dueño.

## La idea

Casi todas las apps de finanzas te dicen cuánto dinero tienes. Muy pocas te dicen cuánto **puedes gastar**, que es la pregunta real. Noma parte de ahí: tu balance se divide siempre entre lo que está disponible y lo que ya está guardado para algo.

Está pensada para cómo funciona el dinero en México:

- **Tarjetas y efectivo.** Débito, crédito y lo que traes en la cartera, en un solo lugar. Las de crédito avisan cuando se acerca el corte o el pago.
- **Apartados.** Una cajita de Nu, un apartado de BBVA, un sobre de la despensa. No son cuentas aparte: son una parte con nombre del dinero que ya está en tu tarjeta, tal como funcionan en el banco. Pueden generar interés.
- **Objetivos.** Un enganche, un viaje, una laptop. Cada uno vive en un lugar concreto y va sumando hasta su meta, con una sugerencia de cuánto ahorrar al mes para llegar a tiempo.
- **Mensualidades y fondos programados.** Los meses sin intereses y la quincena, como recordatorios que tú confirmas; nada se registra solo.

Todo vive en tu teléfono. No hay cuenta, no hay registro, no se manda nada a ningún servidor.

## Cómo está hecha

React Native con Expo. Tema oscuro propio, sin librerías de componentes.

Para correrla:

```
npm install
npx expo start
```

Y abres el proyecto con la app de Expo Go en tu teléfono.

## Estado

No está publicada en la App Store ni en Google Play. Es un proyecto en desarrollo, pero funciona de punta a punta: puedes descargar el repositorio y correrla hoy mismo con las instrucciones de arriba.
